\section*{Data and Code Availability}
\noindent The forward-view cabbage-robot guidance dataset (two field runs,
$1482$ forward-view cabbage frames at $640\times480$ screened from $1$\,fps sampling, with the per-frame
guidance logs), the $150$-frame hand-labelled ground-truth subset, and the
detector-free guidance code will be made publicly available upon publication. The
remaining baseline comparisons of Table~\ref{tab:res-pending} will be released
once they are complete. A repository link and archival DOI will be provided in the
camera-ready version.
