\section{Results}
\label{sec:results}

This section reports the empirical evaluation of CALM-Row. \emph{No dataset-level numbers are filled in yet}: every quantitative cell is a placeholder (``\texttt{--}'' in tables, ``[TODO]'' in prose) to be completed once the pre-registered runs of the A/B protocol (Section~\ref{sec:setup-ab}; see also the experiment plan) have finished. The table structures, comparison arms, metrics, and statistical tests below are fixed in advance so that the analysis is confirmatory rather than exploratory. The only concrete number stated anywhere in this paper is a synthetic, mechanism-level sanity check that is \emph{not} a dataset result and is labelled as illustrative (Section~\ref{sec:res-synth}).

We restate the canonical evaluation design so the tables are self-contained. Four guidance-line readout arms are compared. Arms \textbf{A} (equal-weight least squares through box centroids, the Diao-style recipe~\cite{diao_yolox}), \textbf{A$'$} (RANSAC least squares), and \textbf{B0} (precision-weighted GLS using the \emph{raw} variance of the existing DFL box-edge distribution~\cite{gfl}) share a single stock detector checkpoint and differ only in the CPU-side readout, so their comparison is paired per frame and free of training noise. Arm \textbf{B} (full CALM-Row) is trained with the distance-aware calibration loss $L_{\mathrm{DDC}}$ and the line-stability loss $L_{\mathrm{LSL}}$ and uses the calibrated precision-weighted GLS readout with weights $w_i = 1/\sigma_{c_x,i}^2$. The decomposition is deliberate: \textbf{B0 vs.\ A} isolates the gain from \emph{weighting alone} (free, no extra training), while \textbf{B vs.\ B0} isolates the additional gain from \emph{training the detector to be calibrated and line-aware}. The primary metric is heading error (deg), which is controller-independent; line-fit RMSE (px and, where the px$\rightarrow$cm homography of Section~\ref{sec:setup-homography} applies, cm) and closed-loop cross-track error (cm) are secondary; calibration (ECE), detection (mAP@50, mAP@50--95), and edge latency/FPS support the deployment argument.

\subsection{Paired significance tests (T2)}
\label{sec:res-stats}

Because A, A$'$, and B0 are evaluated on the identical checkpoint and B is paired per frame against them, the comparisons are tested with the Wilcoxon signed-rank test on per-frame heading error (with 5 seeds, normality cannot be assumed for a $t$-test). Table~\ref{tab:res-stats} reports the median paired difference, the Holm--Bonferroni-adjusted $p$-value across the confirmatory family, and the Cliff's $\delta$ effect size. The pre-registered primary hypothesis H1 (CALM-Row beats equal-weight LS on heading error) passes only if the adjusted $p<0.05$ \emph{and} $|\delta|\ge 0.33$, i.e.\ the effect must be both significant and non-trivial. The two decomposition rows (B0 vs.\ A; B vs.\ B0) are reported regardless of outcome so that the source of any gain --- free weighting versus calibrated training --- is stated plainly.

\subsection{Neck-agnosticity (T4)}
\label{sec:res-neck}

\subsection{Synthetic mechanism illustration (not a dataset result)}
\label{sec:res-synth}

To make the precision-weighting mechanism concrete \emph{independently} of any dataset, the reference implementation includes a small synthetic check (a controlled \texttt{numpy}/\texttt{torch} demonstration, not an experiment on real imagery). Box-edge logits are generated so that near boxes have sharp DFL distributions (low variance $\sigma_e^2$) and far boxes have flat distributions (high variance); the far centroids are then corrupted with injected lateral noise. On this fixed synthetic configuration, fitting the guidance line $x = a\,y + b$ with equal weights yields an \emph{illustrative} heading error of $1.16^\circ$, whereas the precision-weighted GLS fit with $w_i = 1/\sigma_{c_x,i}^2$ yields $0.65^\circ$ on the same points. These numbers are reported purely as an \textbf{illustration of the mechanism} and are \emph{not} a dataset result: they show that down-weighting high-variance far boxes recovers a more accurate heading when the variance genuinely tracks reliability. The corresponding real, de-circularized evidence is the far-field analysis accompanying Table~\ref{tab:res-stats}, measured on un-manipulated CRDLD frames with mask-derived ground-truth lines.

\subsection{Summary of planned findings}
\label{sec:res-summary}

Taken together, the tables above are designed to answer four questions, each tied to a core evaluation requirement. (i)~\emph{Does the application improve?} Tables~\ref{tab:res-main}--\ref{tab:res-stats} measure navigation directly in heading (deg) and cross-track (cm), not detection mAP. (ii)~\emph{Is the comparison against real prior art?} Arms A/A$'$ reproduce published line-fitting recipes~\cite{diao_yolox}, and the system-level positioning (reported separately) places CALM-Row against crop-row pipelines~\cite{cth1,rowdetr,alnet} on the same split, GT line, and device. (iii)~\emph{Is the analysis rigorous?} Multiple seeds, per-frame paired Wilcoxon tests with Holm correction, effect sizes with bootstrap CIs, and a separated across-seed/across-field variance budget are all pre-registered. (iv)~\emph{Is the uncertainty real rather than a relabelled ``depth''?} Calibration is measured (ECE, reliability) against \emph{realised} localization error and tested for survival under INT8, using only the existing DFL distribution~\cite{gfl} rather than a separate uncertainty head~\cite{klloss,gaussianyolo}. All cells will be populated once the runs in the experiment plan complete.
